# 插件清单（astrbot_plugin_plugin_list）

统计展示 AstrBot 已安装插件的清单，并通过无状态的二级指令查看指定插件的全部指令。

仓库：<https://github.com/PhiLia011/astrbot_plugin_plugin_list>

## 指令

以下示例中的 `-` 是本机当前的唤醒前缀，实际以你的 AstrBot 配置为准（提示文案会自动跟随配置）。

| 指令 | 说明 |
| --- | --- |
| `-插件列表` / `-插件清单` | 列出已加载插件的展示名、版本、启用状态、指令数，并给出第三方 / 内置、启用 / 禁用的统计 |
| `-查看延迟检测插件帮助` | 二级页面：该插件的版本、作者、状态、简介，以及全部指令（指令名、别名、参数、说明、所需权限） |

插件名匹配规则（`查看xx插件帮助` 中的 `xx`）：

1. 先精确匹配展示名 / 插件名 / 目录名，匹配时忽略大小写与 `astrbot_plugin_` 前缀；
2. 未命中则做唯一子串匹配，例如 `查看延迟插件帮助` 也能命中「延迟检测」；
3. 命中多个会列出候选并提示写得更精确；零命中会提示未找到。

## 安装

1. 把 `astrbot_plugin_plugin_list` 整个目录放到 AstrBot 的插件目录（本机为 `C:\Users\Firefly\.astrbot\data\plugins\`）；
2. 在 WebUI 的插件管理页面点击「重载插件」（或重启 AstrBot）；
3. 在群聊 / 私聊发送 `-插件列表` 验证。

## 行为说明

- 两个页面都以**图片**发送：插件自己调用 AstrBot 内置的文转图能力出图，因此不受核心 `t2i_word_threshold`（本机为 1500 字）限制，短文本的详情页同样能出图。渲染失败时自动回退为纯文本。
- 出图走**本地渲染**（PIL）：官方远端 t2i 端点不稳（实测 `t2i.soulter.top` 502、`t2i.rcfortress.site` 429），远端失败要等十几秒才降级，本地渲染约 1 秒且无网络依赖。
- 本地渲染字体不含 emoji，所以文案使用 `√`（启用）、`×`（禁用）、`[内置]`、`[已禁用]`、`├`、`│` 等在 CJK 字体里可正常显示的符号；行首的空白会被渲染器丢弃，缩进一律用可见字符。
- 清单行不使用 `10.` 这类行首序号（渲染器会把它当成有序列表，仅预留 30px 导致正文串行），指令编号改用 `[10]`。
- 只统计“已成功加载”的插件：加载失败、不在插件注册表里的插件不会出现在清单中（只出现在服务端日志与 WebUI 的失败列表里）。
- 指令信息来自 AstrBot 的指令注册表，因此会跟随 WebUI 中的重命名、别名与禁用状态；被禁用的插件仍可查看指令，但页面顶部会提示“该插件已禁用，以下指令当前不会生效”。
- 版本号会自动去掉重复的 `v` 前缀（metadata 里写 `v0.3` 时展示 `v0.3` 而不是 `vv0.3`）。
- 无配置项、不注册 LLM 工具、不保存任何用户或群会话状态。
- 私聊场景下与 AstrBot 其他指令一致，可以不写唤醒前缀。

## 自定义外观

**设计优先级：文字先看得清，图片其次。** 字号按可读性来定；文字在图上放不下时，会把画布向下延展
（接一段模糊压暗的延续区）给文字让位，而不是一味缩小字号。文字由插件自己排版，直接画在底图上，
不会再有核心 t2i 那层带 AstrBot 标题栏的浅色卡片。

在 WebUI 的插件配置页可以调整出图外观（配置文件：`data/config/astrbot_plugin_plugin_list_config.json`）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 图片底图 | `assets/bg_user.png` | 底图来源。留空 = 回退核心默认渲染；支持 `http(s)` 链接、绝对路径、相对插件目录的路径（仓库也附了渐变底图 `assets/bg_default.jpg`） |
| 排版方式 | `auto` | `auto`=能压在图上就压、装不下就向下延展画布；`overlay`=必须压在图上（装不下才缩字号）；`below`=文字始终放在图片下方的延展区 |
| 文字列数 | 1 | 1 或 2。双列能降低高度，但**只适合宽图**：底图宽 896px 时每列仅约 330px，长条目会被折成两行；底图 ≥1200px 宽才划算 |
| 字号(px) | 0 | 0 = 自动（默认约图片宽度的 1/30，且不小于 22px）；填具体值则固定该字号，放不下就延展画布 |
| 文字最多占图片高度(%) | 100 | 仅对"压在图上"有意义：超过该比例就改走下方延展区，不缩小字号 |
| 文字位置 | `bottom` | `top` / `center` / `bottom`，仅在文字压在图上时生效 |
| 文字颜色 | `#FFFFFF` | 十六进制色值 |
| 行距(%) | 145 | 100~240 |
| 文字区压暗(%) | 60 | 文字区域顶部短渐变过渡、其余均匀压暗；越大文字越清晰，0 = 只靠文字描边 |
| 底图压暗程度(%) | 15 | 整张图的压暗程度（0~90） |
| 四周留白(px) | 48 | 文字与图片边缘的距离（0~240） |
| 使用 WebUI 的文转图 HTML 模板 | 关 | 打开后走远端 t2i 服务套用 HTML 模板 |
| 模板名 | 空 | 留空跟随全局“文转图模板”；也可指定模板名，如 `plugin_list` |

**换成自己的底图**：把图片放进插件目录（例如 `assets/mybj.jpg`），然后把「图片底图」改成该路径；也可以直接覆盖
`assets/bg_user.png`。插件里还附了另一张渐变色底图 `assets/bg_default.jpg` 备用。

> `assets/bg_user.png` 是作者自用的示例底图，随插件附带仅用于默认出图效果；若要用于其他用途请自行确认图片版权。

## 两种出图路线

| | 本地渲染（默认） | HTML 模板（`使用 WebUI 的文转图 HTML 模板`） |
| --- | --- | --- |
| 渲染方式 | PIL 直接绘制 Markdown，再按配置叠底图 | 把 HTML 模板 POST 给远端 t2i 服务 |
| 是否联网 | 否，约 1 秒 | 是，需远端服务可用 |
| 可定制 | 底图、留白、圆角、透明度 | 任意 HTML/CSS（可换字体、布局、底图） |
| 现状 | 可用 | 官方端点实测 502 / 429，会超时十几秒后自动回退到本地渲染 |

若要用 HTML 模板：本插件已附一份 `t2i_template/plugin_list.html`（已放入 `data/t2i_templates/plugin_list.html`），
可在 WebUI「文转图模板」里看到并继续修改；模板里把 `--bg-image` 换成自己的图片链接或 base64 即可换底图。
启用后只影响本插件的两张图，不会改动全局模板。
